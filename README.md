
# Examen AMS — Análisis y Modelado de Sistemas

## Descripción

Este repositorio contiene dos casos de estudio desarrollados para el **Examen AMS**, aplicando conocimientos de análisis, modelado y gestión de proyectos de software.

## Caso 1. Análisis mediante diagramas

Se analizaron los requerimientos del caso de estudio y se elaboraron los diagramas correspondientes para representar la estructura, los procesos y el funcionamiento del sistema.

##  Caso 2. Gestión de proyecto con Jira

Se organizó un proyecto de desarrollo web con **Spring Boot**, utilizando la metodología **Scrum**.

Se definieron épicas, historias de usuario, tareas, incidencias y cuatro sprints, con una duración total planificada de **14 días**. También se elaboró un diagrama de Gantt mediante **PlantUML**.

###  Distribución de los sprints

| Sprint | Nombre | Duración |
|---|---|---:|
| 1 | Configuración y estructura inicial | 4 días |
| 2 | Desarrollo de API y conexión a BD | 5 días |
| 3 | Validación y preparación para producción | 3 días |
| 4 | Optimización del procesamiento | 2 días |
| **Total** | | **14 días** |

## Herramientas utilizadas

- **Jira:** organización y seguimiento del proyecto.
- **PlantUML:** elaboración del diagrama de Gantt.
- **Diagramas de análisis y modelado:** representación del primer caso de estudio.
